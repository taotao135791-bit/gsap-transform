# Product 360 Spin

| | |
|---|---|
| Industry | product |

| Size | 1080×1080 |
| Beats | 1 |

**Best for:** Hero reveal on a product page or paid social.

## How to use

```bash
node scripts/pick-template.mjs product-360-spin
node projects/product-360-spin/render.mjs --preset vertical --dry-run
```
