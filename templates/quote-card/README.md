# Quote Card

| | |
|---|---|
| Industry | social |
| Duration | 5s |
| Size | 1080×1350 |
| Beats | 2 |
| Accent | `#FFFFFF` |

**Best for:** Instagram / TikTok quote or list post.

## How to use

```bash
node scripts/pick-template.mjs quote-card
node projects/quote-card/render.mjs --preset vertical --dry-run
```

## Recipe link

This template composes primitives from [motion-primitives](../../skills/motion-primitives/SKILL.md). The state contract is in [motion-state](../../skills/motion-state/SKILL.md).
